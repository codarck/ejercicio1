# 📌 Proyecto de NatuPeru

Este es un proyecto desarrollado con **Vue 3 + Laravel**, me acompleje mensando que era algo mas complejo y utilice primero vue solo y luego al final Vue3 con laravel, aunque laravel fue innecesario 

## 🚀 Características

✅ Modal para agregar usuarios  
✅ Validaciones en tiempo real  
✅ Envío de datos usando `fetch`  
✅ Notificación con `SweetAlert2`  

## 🛠️ Tecnologías utilizadas

- Vue 3 con `script setup`
- Tailwind CSS para el diseño
- Laravel 11 // ESTA POR DEMAS
- SweetAlert2 (para alertas)
- Fetch API (para peticiones HTTP)
